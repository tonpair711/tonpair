網站速度會不會影響排名？Core Web Vitals 是什麼

客人點進你的網站，畫面卡了兩三秒才跑出來，這幾秒鐘看起來不長，但對手機上滑得很快的使用者來說，常常等不到就直接划走了。

最後更新：2026 年 9 月 2 日　·　對頻設計

先講結論

Core Web Vitals 是 Google 制定的一套網站使用體驗指標，衡量載入速度、互動反應與畫面穩不穩定。網站速度會影響 SEO 排名，但更直接的衝擊是客人流失，Google 的行動網站研究指出，載入時間超過 3 秒，約 53% 的行動使用者會直接離開。改善速度不一定要花大錢重做網站，壓縮圖片、減少不必要的外掛與腳本，就能改善不少。

Google 官方已經明確把「頁面體驗」（其中包含 Core Web Vitals 這組指標）納入排名考量之一。但比起排名，更直接的影響是：速度慢的網站，客人根本等不到內容出現就先划走了，內容再好，沒人願意等。

這篇把 Core Web Vitals 的概念講白話，也講幾個常見的拖慢原因，讓你找廠商討論時知道該問什麼、自己網站有沒有這些問題。

店家最常問的幾題

網站速度會不會影響排名？Core Web Vitals 是什麼

Core Web Vitals 是 Google 制定的一套網站使用體驗指標，衡量載入速度、互動反應與畫面穩不穩定。網站速度會影響 SEO 排名，但更直接的衝擊是客人流失，Google 的行動網站研究指出，載入時間超過 3 秒，約 53% 的行動使用者會直接離開。改善速度不一定要花大錢重做網站，壓縮圖片、減少不必要的外掛與腳本，就能改善不少。

Core Web Vitals 到底是什麼？

這是 Google 制定的一套量化網站使用體驗的指標，主要看三件事：LCP（最大內容繪製，網站主要內容多快跑出來）、INP（互動延遲，客人點一下之後多快有反應）、CLS（版面穩定性，畫面元素會不會跳來跳去讓人點錯）。

這三項會直接影響 Google 對你網站體驗的評分，也是排名因素之一，但不是唯一因素。

網站速度真的會影響 SEO 排名嗎？

會，但不是唯一因素，也不是最大的一個。Google 官方已明確把頁面體驗納入排名考量之一，但速度慢造成的更直接衝擊是客人自己流失，依 Google 2017 年公布的行動網站數據，載入時間從 1 秒拉長到 3 秒，使用者跳出的機率會上升約 32%；拉到 5 秒，跳出機率增加約 90%。

換句話說，就算排名沒有明顯受影響，速度慢也會讓好不容易導進來的流量白白流失，這比排名掉幾名更可惜。

最常見拖慢網站速度的原因有哪些？

常見原因有幾種：圖片檔案太大、沒壓縮（手機拍的原圖直接上傳，動輒好幾 MB）、載入太多不必要的第三方外掛或腳本（分析工具、彈跳視窗套件）、字型檔案太多或載入方式不對造成畫面閃爍、以及伺服器回應太慢（尤其是用未優化的 CMS，每次都要即時查資料庫）。

小店網站最常踩的其實就是第一項，上傳沒壓縮的原圖，隨便一張就拖慢整頁載入速度。

為什麼純靜態網站通常比較快？

純靜態網站的每一頁都是預先寫好的固定檔案，伺服器收到請求直接回傳檔案，不用即時查資料庫或跑後端運算；用 CMS 架的動態網站（例如沒優化過的 Wix、WordPress）常常每次請求都要組裝頁面，架構複雜度較高。

我們自己的網站就是走零 build 的純靜態架構，搭配 Cloudflare 的全球節點部署，不用犧牲速度換內容管理的方便。

怎麼知道自己網站的速度好不好？

最簡單的方法是用 Google 官方免費工具 PageSpeed Insights，貼上你的網址就會跑出 Core Web Vitals 分數與改善建議，不需要懂技術。定期檢測（尤其是改版之後）能提早發現速度變慢，不用等客人抱怨才處理。

改善速度一定要花大錢重做網站嗎？

不一定。很多問題可以用相對低成本的方式改善：壓縮圖片、拿掉用不到的外掛與腳本、開瀏覽器快取、圖片延遲載入，都是常見的局部調整，不用整個網站重做。

但如果網站架構本身就是瓶頸（例如用了過時的技術、主機資源不夠），局部調整效果有限，這種情況才需要考慮較大幅度的重做，可以先讓我們看一下網址再判斷值不值得。

手機上的網站速度，跟電腦上會不會不一樣？

會，而且落差通常比想像中大。手機的網路環境（行動網路訊號不穩）跟硬體效能都比電腦弱，同一個網站在電腦上開起來很快，手機上可能明顯變慢，尤其是圖片沒做響應式處理、電腦版跟手機版讀的是同一份大圖的情況。

PageSpeed Insights 這類工具會分開跑「行動裝置」與「電腦」兩組分數，看報告的時候記得兩邊都看，不要只看電腦那組，你的客人多半是用手機在找你。

想知道自己網站的速度卡在哪裡？

把網址給我們看一下，我們會用 PageSpeed Insights 幫你抓出真正的瓶頸，照實告訴你值不值得改、改起來大概多少工。
