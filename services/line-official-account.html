諮詢 LINE 官方帳號設定

先講結論

LINE 官方帳號代設定分兩種：只做圖文選單與帳號門面 NT$6,800 起；圖文選單加上關鍵字自動回覆的接單自動化 NT$12,000 起。設定好之後，客人打「多少錢」「怎麼訂」「營業時間」會自動收到回覆，需要判斷的問題再轉給你。純文字回覆討論好內容通常一到兩天就能上線。

完整價格對照在收費參考，估價與諮詢都免費，聊完不一定要合作。習慣用 LINE 的話，直接加 LINE 問（ID：@007bbtpd）。

先試試看

我們自己的官方帳號就是這樣設定的。用手機加對頻設計 LINE 好友（電腦版請在 LINE 搜尋 ID：@007bbtpd），輸入「看價格」，你會收到一張整理好的報價卡；點下面的圖文選單，看看每一格帶你去哪裡。你的店做出來大概就是這個樣子，內容換成你的。

兩種方案差在哪？

  • 圖文選單重塑（NT$6,800 起）：聊天視窗下方那排固定按鈕重新設計，加上頭像、封面、帳號名稱與狀態消息整理成同一套品牌樣子。不含自動回覆設定。適合已經在用官方帳號、只是選單很亂或根本沒設定的店家。
  • 接單自動化（NT$12,000 起）：圖文選單加上關鍵字自動回覆規則。我們會先跟你整理客人最常問的問題，例如價格、怎麼預約、營業時間、停車、付款方式，每一題設定對應的關鍵字與回覆，必要時做成排版過的圖文卡片。

還沒開官方帳號也可以，從開帳號一起處理。網站、LINE、自動化三件事想一起做，有整合方案 NT$68,000 起。

自動回覆做得到什麼、做不到什麼？

先講清楚，免得期待落差：

  • 做得到：固定答案的問題自動回（價格區間、地址、營業時間、預約方式）、選單一點就跳到網站／訂購表單／地圖、加好友時自動送出歡迎訊息。
  • 做不到：關鍵字自動回覆不是真的會聊天的機器人，客人問了沒設定過的問題它不會懂。需要看個案、處理客訴的狀況，一定要有真人接手，我們會把「轉真人」的路設計好。
  • 要另外做：客人在 LINE 下單後資料自動進試算表、自動對帳這類，屬於訂單自動化，走自動化腳本（NT$8,000 起）或小型客製工具。

想先了解原理，可以看 LINE 接單怎麼自動化與LINE 官方帳號圖文選單實務。

流程與時間

  1. 整理問題：你回想最近一個月客人最常問什麼，我們一起整理成清單。
  2. 寫回覆、設計選單：回覆文字用你平常講話的口氣，不要像機器人。
  3. 設定與測試：在你的帳號後台設定好，用另一支手機實際打一輪。
  4. 教你改：價格變了、營業時間改了，教你在後台怎麼改；不想自己改可以談維護。

純文字回覆討論好內容，通常一到兩天就能上線；做成排版過的圖文卡片會多花一點時間調版面，整體還是幾天內能完成的規模，不是幾週的工程。全程線上，不用見面也能做完。

常見問題

LINE 官方帳號代設定多少錢？

只做圖文選單與帳號門面（頭像、封面、名稱、狀態消息）NT$6,800 起；圖文選單加上關鍵字自動回覆的接單自動化 NT$12,000 起。都是未稅參考起價，依問題數量與要不要做圖文卡片報價，估價免費。

我還沒有 LINE 官方帳號，可以從頭幫我開嗎？

可以，從申請帳號開始一起處理。帳號會用你的名義申請、管理權限在你手上，我們只是協助設定。

自動回覆會不會讓客人覺得很冷漠？

會不會冷漠看回覆怎麼寫。我們會用你平常講話的口氣寫，而且每一則自動回覆都留一條路讓客人找真人。固定答案的問題讓帳號秒回，客人反而不用等你忙完才拿到價格。

設定好之後我自己能改內容嗎？

可以。價格、營業時間這類常改的內容在 LINE 官方帳號後台就能改，交件時會教你怎麼改；不想自己動手的，可以談維護方案代為更新。

不在台南也可以做嗎？

可以，LINE 官方帳號設定全程線上就能完成，全台都能服務。在台南想當面談，也可以約時間。
