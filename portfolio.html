網站開發形象官網

伊登森活 Idun Beauty SPA｜品牌官網

台南東區美容 SPA 品牌的形象官網，共 8 個頁面：品牌故事、空間介紹、服務項目、方案價目、交通位置等，並導流至 LINE 官方帳號預約。

當時的狀況，和我們做的事

原網站是單頁式架構，搜尋引擎只看得到一個網址，各服務項目無法被個別搜尋到。我們將其重構為 8 個獨立頁面，每頁有專屬網址、標題與描述，並加上在地商家結構化資料（LocalBusiness）、sitemap 與乾淨網址設定，讓「台南 美容 SPA」等在地搜尋能找到對應頁面。

小型客製工具會員系統

Loverolling｜店家會員累點系統

為店家打造的線上會員系統：消費累點、QR Code 出示、點數兌換與後台管理，會員、店員、老闆各有不同的操作介面與權限。

當時的狀況，和我們做的事

店家原本用紙本集點卡，容易遺失也難統計。我們以免月費的雲端架構打造專屬會員系統：客人手機出示 QR Code 即可累點與兌換，老闆從後台就能看會員與點數狀況，並附上專屬操作說明頁，店員當天就能上手。
